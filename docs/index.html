Personal Task Tracker API

REST API to register, log in, and manage personal tasks.
Spring Boot · Java 21 · PostgreSQL · JWT

Try it live

  • Swagger UI — interactive API explorer
  • Health check
  • Source code on GitHub

What it does

  • Register and log in with JWT authentication
  • Create, list, update, and delete your own tasks
  • Per-user ownership enforced at the SQL level (404 for other users' tasks)
  • Documented with OpenAPI / Swagger UI

How it is built

Java 21 · Spring Boot · Spring Data JPA · Spring Security · Flyway · JUnit 5 · Mockito · GitHub Actions · Docker · Render · Neon Postgres

The API runs on Render's free tier — it sleeps after 15 minutes of inactivity, so the first request may take ~30 seconds to wake up.
